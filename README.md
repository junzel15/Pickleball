# Pickleball Hyper

Landing page for the Pickleball Hyper Android app.

- `index.html`, `style.css` and `main.js` make up the single-page site.
- The **Download APK** buttons link to the APK on Google Drive (https://drive.google.com/file/d/1kea0Zpujf5nrP0XU4jS9x_JvQgA9CY2m/view). To release a new build, use **Manage versions** on that Drive file to upload the new APK so the link stays the same, then update the size shown in `index.html`.
- `sw.js` only exists to remove the old game's offline cache from returning visitors' browsers.
